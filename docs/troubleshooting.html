Troubleshooting

First: Copy Diagnostics

Click in the field where Nib doesn't behave, then choose Copy Diagnostics from Nib's menu. After a 5-second countdown, a report is copied to the clipboard. It lists every step live checking takes, with ✓ or ✗, and stops at the step that fails. It contains numbers and settings only, never your text, so it's safe to paste into an issue.

No underlines anywhere

  • Is Nib running? Look for the nib icon in the menu bar. Turn on Open at login in Settings so it starts after a restart.
  • Is it paused? The icon has a slash, and the menu says Resume Nib. Tap ⌘⌘.
  • Check the menu's status line for “Needs Accessibility permission”, “No API key” or “Live checking paused: …” (for example, a quota or key problem).
  • After an update, macOS sometimes needs the Accessibility permission again: remove Nib with −, add it back, and click Restart Nib in the setup guide.

Slack and other Electron apps

  • Nib asks Slack for its accessibility information, which Slack builds a few seconds later. Underlines may take a moment after Slack or Nib starts. Nib retries by itself.
  • If underlines stay away, click into the message box again or switch channels, then run Copy Diagnostics.
  • ⌥⌥ works through copy and paste here, so formatting inside the corrected text can be lost.

Chrome and other Chromium browsers

  • Text areas, input fields and rich editors (contenteditable) are supported. Nib switches on the browser's accessibility support for web pages, which can cost a little speed on very large pages.
  • Some web editors (Google Docs, canvas-based editors) don't expose their text; use ⌥⌥ there.

VS Code (experimental)

  1. In Nib: Settings → Live checking → Allow underlines in code editors.
  2. In VS Code: set Editor: Accessibility Support to on (Settings → search “accessibility support”).
  3. Only prose files are checked: .md, .markdown, .txt, .rst, .adoc, .tex, files with no extension such as README, and untitled documents. Code is never sent.

Underline positions assume a monospaced editor font. Folded regions aren't handled yet.

Chinese or Korean isn't checked

Check Settings → Languages to check: languages you've unticked aren't checked as you type (⌥⌥ still works). Very short text (fewer than five characters) isn't checked live.

“Couldn't apply… it's on the clipboard”

The app didn't accept the change (or Nib couldn't confirm it), so the corrected text was left on the clipboard. Paste it with ⌘V.

Provider errors

Use Test connection in Settings. Errors are shown in plain words: invalid key, no credit or quota left, model not found, or rate limit reached. Try another model with Load models.
